# Team Obsidian MC Website

This is the official website for Team Obsidian MC, built with Next.js, Lenis, and GSAP.

## Features

- Modern, scroll-based animations and transitions
- Team member showcase with interactive cards and parallax particles
- Inhabitants carousel and lore sections
- Gallery and concept art sections

## Visit the Site

Visit the [live website](https://your-vercel-site-url.vercel.app) (hosted on Vercel) to explore Team Obsidian MC:

Enjoy interactive galleries, team showcases, and smooth animations designed for an engaging experience.

## Project Structure

- `app/` — Main application code
  - `components/` — UI components
  - `globals.css` — Global styles
  - `layout.tsx` — Root layout
  - `page.tsx` — Main landing page
  - `Animate.tsx` & `AnimationProvider.tsx` — Power the smooth animations and transitions you see throughout the site
  - `.anim.ts` files — Define the unique animation effects for each section and component, making the site visually engaging
- `public/` — Static assets (images, icons, etc.)

## Scripts

- `npm run dev` — Start development server
- `npm run build` — Build for production
- `npm start` — Start production server
